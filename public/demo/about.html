Về bài lab này

Bài lab yêu cầu một browser đơn giản gửi được ba loại request GET, POST, HEAD tới một web server.

Với GET và POST, browser đọc HTML trả về rồi thống kê chiều dài và số lượng tag <p>, <div>, <span>, <img>.

Với HEAD, browser chỉ nhận header và hiển thị thông tin tài nguyên.

Vì sao phải fetch qua server?

Trình duyệt chặn JavaScript đọc nội dung trang khác origin (CORS), nên web app gửi URL về server Node; server fetch hộ rồi trả JSON. Nhờ vậy vẫn phân tích được HTML của bất kỳ trang nào.
